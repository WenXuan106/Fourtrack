How the iPad-safe AI mode works
Fourtrack runs the real HTDemucs ONNX model through ONNX Runtime Web. It uses single-threaded WASM on iPad, processes one model chunk at a time, overlap-adds the predictions, converts finished pieces to 16-bit PCM, and stores those pieces in IndexedDB. The full-length Float32 stem arrays are never kept in memory.

This is still heavy AI processing. A long song can take several minutes on an iPad, but the memory usage is substantially lower than the old full-buffer method.
