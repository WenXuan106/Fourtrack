HTDemucs AI browser engine

Fourtrack runs HTDemucs through ONNX Runtime Web. Audio is converted to stereo 44.1 kHz before inference. The model processes 343,980-sample chunks with overlapping reconstruction.

The AI model is large and browser inference is demanding. The first run downloads roughly 166 MB of model data. Longer tracks require considerably more RAM, especially on iPad and iPhone.
